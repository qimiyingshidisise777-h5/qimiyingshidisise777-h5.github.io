NOTE 01手闲，不是剧荒
起格 · 别硬找 凌晨把封面滑到底，手指累了，胸口还是空的。“777 部总有一部适合我”这句不成立的——选项越多，胃口越像被搅浑的水。先别点，先问：现在想被逗笑、被哄，还是只想有人不催？答案出来，片自己会来找你。
NOTE 02倍速是赶路，0.5x 才叫看
剔快 · 留一顿 一集压进二十分钟，剧情全对，心口空一块。你跳过的是“没事发生”的那几秒，可情绪常常就藏在那几秒里。练一次：只盯门把手、杯沿、雨落到肩膀——看不懂也别查解说。
NOTE 03免费的那口，账单在别处
剔满 · 算清账 不收会员的站，常常收权限、收跳转、收你那台被装满的手机。“免费高清”四个字越亮，越该问一句谁在付钱。想看就去持证平台，单部单付，看完就走，不欠谁停留时长。
NOTE 04重看不是没出息
认熟 · 回旧屋 一部你背得出转场的，比十部新剧顶用。熟到空气都认得的那间屋，是你在乱日子里给自己留的。别嫌它旧，能让你卸肩膀的，才算看过。
NOTE 05允许一无所获
认丧 · 不写总结 别要求每部片都给一句中心思想，也别逼自己发条“有深度”的动态。被治愈是产业，不是义务。看完什么道理都没有，就把额头贴会儿凉碗——奇米这页不考核你。
NOTE 06爽完别表态
翻桌 · 十分钟 想在屏幕里让那个坏人跑掉，就让他跑。那是气压阀，不是你的人设。十分钟，不加长、不追第二集、不跟人辩论——把牙关松下来，天亮照常忍，但你今晚歇过。
NOTE 07黑场也是内容
停格 · 关灯 字幕起，画面暗，那二十秒是导演留给你的回魂位。别拿它滑下一条。第七格我们故意空着：你带着那句话躺下，比带着一部片入睡干净。
